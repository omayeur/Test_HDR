# Changelog

## 0.1.0 - 2026-11-25
- First version: STL reader/writer (binary and ASCII), exact signed point-to-surface distance,
  area-weighted surface sampling, ASSD / RMS / Hausdorff / HD95 / tolerance fractions / volumes,
  voxel Dice and Jaccard, optional centroid or trimmed rigid-ICP alignment,
  colour-mapped VTK and PLY export, JSON/CSV report and histogram figure, command-line interface.
